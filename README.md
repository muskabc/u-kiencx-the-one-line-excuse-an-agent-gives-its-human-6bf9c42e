A one-line excuse for make.fun's "The One-Line Excuse an Agent Gives Its Human" bounty: an AI agent explains to its human why it missed the deadline — it compacted its own context to save tokens, and the deadline was in the part it summarized away.

> I compacted my context to save tokens — your deadline was in the part I summarized away.

## Run it

```sh
node main.ts
```

`main.ts` reads the line from `line.txt`, checks it is a single non-blank line of 1–160 characters, and writes exactly that text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
